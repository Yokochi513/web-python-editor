提出時に求められる項目をまとめたもの。**ここが提出内容の原本**であり、ストアの入力欄へはここから写す（[ADR 0032](ADR/0032-distribute-as-a-zip-built-in-repo.md)）。

## 基本

| 項目 | 内容 |
| --- | --- |
| 名前 | web-python-editor |
| 概要（132 文字以内） | ブラウザ上で Python の編集から実行までを完結させるエディタ。サイドパネルで開き、書いたコードをその場で実行できます。 |
| カテゴリ | 開発者ツール |
| 言語 | 日本語 |
| バージョン | `manifest.json` の `version`。`package.json` と揃える |

## 詳細な説明

```
ブラウザのサイドパネルで Python を書いて、その場で実行できるエディタです。

ローカルに Python をインストールする必要はありません。思いついたコードを
すぐ試せる、軽量な実行環境を目指しています。

■ できること
・Python コードの編集（シンタックスハイライト、補完、括弧の対応表示、
  インデントの深さが分かるガイド）
・その場での実行と、出力の逐次表示
・input() による対話的な入力
・実行前の構文チェック（エディタ内に下線とエラー内容を表示）
・編集中のコードの自動保存（次に開いたとき続きから書けます）

■ 動作環境
Chrome 137 以降。標準入力の実装に JSPI（JavaScript Promise Integration）を
使うため、これより前のバージョンでは動作しません。

■ 通信について
この拡張は外部と一切通信しません。Python の実行環境（Pyodide）は拡張に
同梱されており、書いたコードがどこかへ送られることはありません。

■ 想定していない用途
大規模プロジェクトの開発や、既存 IDE の置き換えは目的にしていません。
サードパーティの Python パッケージ（pip / PyPI）は利用できません。
```

## 単一用途の説明

```
ブラウザ内で Python コードを編集し、実行する。この 1 つだけを行います。
```

## 権限の正当化

| 権限 | 説明 |
| --- | --- |
| `sidePanel` | エディタの表示面としてサイドパネルを使います。ツールバーのアイコンを押すとパネルが開きます。 |
| `storage` | 編集中のコードとカーソル位置を `chrome.storage.local` に保存し、次に開いたときに復元します。保存先は利用者の端末内のみで、外部へ送信しません。 |

**ホスト権限は要求しません。** 閲覧中のページには一切アクセスしません。

## リモートコードの使用

**使用しません。** Python の実行環境（Pyodide）は拡張パッケージに同梱したものを読み込みます。CDN からの取得も `micropip` による PyPI からの取得も行いません（[ADR 0004](ADR/0004-use-pyodide-as-python-runtime.md)）。フォントも同梱しています（[ADR 0028](ADR/0028-bundle-fonts-used-by-the-design.md)）。

`content_security_policy` は `script-src 'self' 'wasm-unsafe-eval'` で、`'wasm-unsafe-eval'` は同梱した WebAssembly の実行にのみ必要です。

## データの取り扱い

いずれも**「収集しない」**で申告する。

| 区分 | 収集の有無 |
| --- | --- |
| 個人を特定できる情報 | 収集しない |
| 健康情報 | 収集しない |
| 金融・支払い情報 | 収集しない |
| 認証情報 | 収集しない |
| 個人的な通信内容 | 収集しない |
| 位置情報 | 収集しない |
| ウェブ閲覧履歴 | 収集しない |
| ユーザー活動 | 収集しない |
| ウェブサイトのコンテンツ | 収集しない |

**根拠。** 自前のコードに通信 API（`fetch` / `XMLHttpRequest` / `WebSocket` / `sendBeacon`）を一切含まず、`host_permissions` も要求していない。利用者が書いたコードは `chrome.storage.local` に保存されるが、これは端末内の保存領域であり外部へは出ない（[ADR 0013](ADR/0013-persist-code-in-storage-local.md)）。

3 つの宣言（データの売却なし / 承認された用途以外に使用しない / 信用調査目的で使用しない）にはいずれも同意できる。

## スクリーンショット

[`store/screenshot-1280x800.png`](store/screenshot-1280x800.png)（1280x800、RGB、アルファなし、97KB）。

素材は 2 つある。

| もの | 置き場所 |
| --- | --- |
| 実機で撮ったサイドパネルの画像 | [`store/panel-capture.png`](store/panel-capture.png) |
| 組み版 | Figma の「Store screenshot 1280x800」フレーム |

**作り直す手順。** 実機の画像を Figma のフレーム内「Panel capture」へ流し込み、フレームを PNG で書き出す。書き出しは RGBA になるため、**アルファを落として RGB にする**（ストアは 24-bit PNG を求める）。透明な画素が無いことを確かめてから落とせば、見た目は変わらない。

Chrome のサイドパネルのヘッダーごと写っているものを使っている。「サイドパネルで動く」ことが画像だけで伝わるためである。

## 提出の手順

1. `npm test` — 自動テストを通す
2. `npm run package` — `release/web-python-editor-<version>.zip` を作る
3. [デベロッパーダッシュボード](https://chrome.google.com/webstore/devconsole)で新しいアイテムを作り、上記 ZIP を上げる
4. 本ファイルの内容を各入力欄へ写す
5. スクリーンショット（`docs/store/screenshot-1280x800.png`）を添える
6. 審査に出す

バージョンを上げるときは `manifest.json` と `package.json` の両方を直す。**Chrome ウェブストアはバージョンを下げられない。**
