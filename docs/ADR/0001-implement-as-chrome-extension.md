# 0001. Chrome 拡張機能として実装する

## ステータス

採用（2026-09-15）

## コンテキスト

ブラウザ上で Python の編集から実行までを完結させるエディタを作る。配布・起動の形態として次の選択肢があった。

- **Web アプリ（通常のサイト）**: URL を開くだけで使える。配布が容易でクロスブラウザ。ただし利用のたびに URL へアクセスする必要があり、オフラインやブラウザ内の他の作業との併用がしづらい。
- **Chrome 拡張機能**: インストール後はツールバーや新規タブから常に手元にある。ローカルストレージや拡張 API を使えるが、Chrome 系ブラウザに限定され、ストア審査と Manifest V3 の制約（リモートコード実行の禁止、Service Worker のライフサイクル等）を受ける。
- **デスクトップアプリ**: 自由度は最も高いが、「ブラウザだけで完結させる」という前提から外れ、インストールの負担も大きい。

本プロジェクトの狙いは「思いついたコードをすぐ書いて試せる」ことであり、エディタを開くまでの手間の小ささを最優先とする。

## 決定

Chrome 拡張機能として実装する。

## 影響

- 対象ブラウザは Chrome（および Chromium 系）に限定する。他ブラウザ対応は当面スコープ外とする。
- Manifest V3 に準拠する。とくに **リモートコードの読み込み・実行が禁止される** ため、Python 実行基盤は拡張パッケージ内に同梱できる方式を選ぶ必要がある（別 ADR で決定する）。
- 拡張のパッケージサイズ、および Service Worker が随時停止するライフサイクルを設計上の制約として扱う。
- 配布は Chrome Web Store を前提とし、審査に通る構成にする。
- どの表示面（ポップアップ / サイドパネル / 新規タブ / 独立ウィンドウ）をエディタの主画面にするかは未決定。別 ADR で決定する。
