# 0030. アイコンは段づけした 4 本の線とする

## ステータス

採用（2026-09-19）

## コンテキスト

拡張にアイコンが無く、Chrome の既定（パズルピース）が表示されていた。ツールバーに常駐する以上、他の拡張と見分けがつく必要がある。[基本設計 §8](../design.md) の manifest にも `icons` / `action.default_icon` が無かった。

意匠として検討したものは次のとおり。

- **Python の公式ロゴを使う / 似せる**: ロゴは PSF の商標であり、派生を作る筋のものではない。
- **プロンプト記号（`>_`）**: 「書いて実行する」を直接示し、ターミナル形式の入力面（[ADR 0012](0012-implement-stdin-as-terminal-with-jspi.md)）とも繋がる。ただし**この意匠の拡張は多く**、ツールバーに並んだときに見分けにくい。
- **段づけした線**: [ADR 0029](0029-show-indent-depth-with-colored-guides.md) で入れたインデントガイドをそのまま印にする。

## 決定

**段づけした 4 本の線**とする。段は 0 / 1 / 2 / 1 で、ブロックに入って戻るという Python のコードの形をそのまま写す。地は透明にする。

色は `syntax/*` の 4 色を使う。

| 線 | 色 | トークン |
| --- | --- | --- |
| 1 本目 | `#4078f2` | `syntax/function` |
| 2 本目 | `#50a14f` | `syntax/string` |
| 3 本目 | `#986801` | `syntax/number` |
| 4 本目 | `#a626a4` | `syntax/keyword` |

**ガイドの `indent/1`〜`indent/4` は使わない。** あちらは地の装飾として意図的に淡くしてあり（[ADR 0029](0029-show-indent-depth-with-colored-guides.md)）、16px のツールバーでは消える。同じ色相の濃い側、すなわち元になった `syntax/*` を採る。

地を透明にするのは、Chrome のツールバーが明暗どちらにもなり得るためである。塗りつぶした地を持つと、片方で四角い板に見える。

## 影響

- [基本設計 §6](../design.md) に `src/icons/`、[§7](../design.md) のコピー対象に同ディレクトリ、[§8](../design.md) に `icons` と `action.default_icon` が加わる。`icons` は拡張の一覧やストア、`action.default_icon` はツールバーで使われるため、同じ 4 枚を両方に指定する。
- Figma に「Icon 128」のフレームを 1 枚足す（[ADR 0008](0008-manage-screen-design-in-figma.md)）。状態を示すアートボードではないため、[§5.3](../design.md) のアートボード表には載せない。
- 書き出した PNG（16 / 32 / 48 / 128px）をリポジトリに置く。**Figma が唯一の原本であり、PNG はその複製である。** 意匠を変える場合は Figma を直してから書き出し直す。
- **書き出しの際はページ背景を一時的に透明にする必要がある。** Figma の書き出しはフレームの塗りが空でもページ背景を合成するため、そのまま書き出すとキャンバスのグレー（`#e5e5e5`）が焼き込まれる。書き出した後はページ背景を戻す。
