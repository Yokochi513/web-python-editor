# 0003. エディタ基盤に CodeMirror 6 を採用する

## ステータス

採用（2026-09-15）

## コンテキスト

「ミニ VSCode」を目指す以上、シンタックスハイライト・行番号・補完といったエディタとしての基本機能が必要であり、`<textarea>` では成立しない。エディタコンポーネントの選択肢は次のとおり。

- **CodeMirror 6**: 軽量でモジュール化されており、必要な機能だけを選んで組み込める。Python のシンタックスハイライト（Lezer ベース）を公式に提供。ライセンスは MIT。
- **Monaco Editor**: VS Code 本体のエディタそのもので機能は最も豊富だが、サイズが大きく Web Worker 前提の構成のため、拡張機能に同梱するには重い。
- **Ace**: 実績はあるが設計が古く、モジュール単位での取り込みがしづらい。

拡張パッケージのサイズを抑えたいという制約（[ADR 0001](0001-implement-as-chrome-extension.md)）と、依存を最小にする方針（[ADR 0002](0002-use-vanilla-js-html-css.md)）から、必要な機能だけを組み込める CodeMirror 6 を選ぶ。

## 決定

エディタ基盤として CodeMirror 6 を採用する。Python のハイライトには `@codemirror/lang-python` を用いる。

## 影響

- CodeMirror 6 は `@codemirror/state`、`@codemirror/view`、`@codemirror/lang-python` など複数パッケージに分かれた ES Modules として配布される。**バンドルして拡張パッケージ内に同梱する必要があり、ビルド工程が必須になる。**
- Manifest V3 はリモートコードの読み込みを禁止するため、CDN からの読み込みは選択できない。バンドル成果物をパッケージに含める。
- 機能（補完、検索、折りたたみ、キーバインド等）はデフォルトで有効にならず、必要な拡張を明示的に組み込む設計になる。どこまで組み込むかは実装時に決める。
- CodeMirror 6 が提供するのは編集機能までで、Python の実行はスコープ外。実行基盤は別途決定する。
